# JavaBasics With OOPs

**JavaBasics** is a beginner-friendly Java learning repository created to practice and understand the fundamentals of Java programming along with **Object-Oriented Programming (OOPs)** concepts. The code examples are written with proper comments to make the concepts easy to follow, understand, and revise.

##  IDE & Java Version

- **IDE:** IntelliJ IDEA
- **Language:** Java
- **Java Version:** Java 17

##  Topics Covered

### Java Basics

- Java Program Skeleton
- Data Types
- Variables
- Type Operators
- Conditional Statements
- Loops
- Packages
- Methods
- Method Parameters and Return Values
- Method Overloading

### OOPs — Object-Oriented Programming

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- `static` Keyword
- `final` Keyword
- Interfaces
- Inner Classes


##  Purpose

This repository is made for **beginners who are learning Java from the basics and want to build a strong foundation in OOPs concepts through practical coding examples**.

Each topic contains simple Java programs with comments explaining the important concepts and syntax.

## How to Practice

If you are a beginner, you can **fork this repository** and practice all the programs on your own PC.

### 1. Fork the Repository

Click the **Fork** button on the GitHub repository to create your own copy.

### 2. Clone the Repository

After forking, copy your repository URL and run:

```bash
git clone https://github.com/your-username/JavaBasics_with_OOPs.git
```

Move into the project folder:

```bash
cd JavaBasics_with_OOPs
```

### 3. Open the Project in Your IDE

You can open the project in **any Java-compatible IDE**, such as:

* IntelliJ IDEA
* VS Code
* Eclipse
* NetBeans

### 4. Check Java Installation

Open the terminal and check your installed Java version:

```bash
java -version
```

Also check the Java compiler:

```bash
javac -version
```

### 5. Run the Code

You can run the programs directly from your IDE.

Or you can compile and run a Java file from the terminal:

```bash
javac FileName.java
java FileName
```


### 6. Practice and Experiment

Don't just read the code. Try to:

* Run the existing programs.
* Modify the code.
* Change values and conditions.
* Add your own examples.
* Write the programs yourself.
* Experiment with different inputs.
* Observe the output.
* Try to understand why the output changes.

> **Fork → Clone → Open → Run → Modify → Experiment → Learn **
